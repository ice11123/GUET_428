小车调试中，很多“程序问题”其实来自供电不足、没有共地、信号电平不兼容或接触不良。学会基础测量，能让你在改代码前先排除硬件条件。

这篇只讨论低压电子实验中的基础概念。任何不确定的供电、裸露导体、发热或异味，都应立即断电并请老师或有经验的同学检查。

## 本篇目标

本篇不是要求你推导复杂电路，而是学会在上电前辨认电源、信号和地，在上电后安全测量一个已知低压电源点，并根据读数决定继续还是立即断电。

一次有效测量必须同时写清被测两点、万用表挡位、预期范围和实际读数。“这里有电”不是完整结论。

## 电压：两个点之间的差

电压必须在两个点之间测量。说“这个点是 3.3 V”时，通常隐含了“它相对于 GND 是 3.3 V”。如果参考点不同，同一个信号的含义也可能不同。

万用表测电压时应并联在被测两点之间。直流电路中，黑表笔通常接参考地，红表笔接被测点。

## 电流：电荷流过路径的多少

电流流经回路，因此测电流时，万用表要串联到回路中。把电流挡像电压挡一样直接跨接在电源两端，可能形成近似短路。

> [!WARNING]
> 不熟悉电流挡时，不要自行测量大电流电机回路。先使用电源显示的电流值，或在老师指导下选择合适量程、表笔插孔和测量方法。

## 电阻与功率：为什么元件会发热

欧姆定律描述电压、电流和电阻的关系：

$$U = I R$$

电功率可用下面的关系估算：

$$P = U I$$

功率最终可能转化为机械能、光、声音和热。驱动芯片、电机或导线异常发热，说明能量消耗超出预期，不能只靠“再试一会儿”判断是否正常。

## 电源和信号不是一回事

电机电源负责提供较大的能量，逻辑电源负责让芯片工作，控制信号负责传递高低电平或脉冲。它们可能使用不同电压，不能只看插头相似就互换。

| 名称 | 主要作用 | 接错后的典型风险 |
| --- | --- | --- |
| 电机电源 | 给电机和功率级供能 | 反接、过压、瞬间大电流 |
| 逻辑电源 | 给主控和逻辑芯片供能 | 芯片损坏或复位 |
| 控制信号 | 表示方向、使能、PWM 等命令 | 逻辑误判或输入过压 |
| GND | 提供共同的电压参考 | 信号漂移、通信失败或误动作 |

“模块由 5 V 供电”不代表它输出的每个信号都适合 3.3 V 主控。判断兼容性要查看原理图、模块说明和芯片数据手册中的输入输出电压范围。

## 为什么通信双方通常需要共地

主控输出高电平时，接收端要知道这个电压相对于什么参考。如果两块板没有共同参考，接收端看到的电平可能漂移，表现为偶发错误或完全无响应。

共地不是把所有电源正极连在一起，而是按设计连接共同的参考地。多路电源系统还要考虑反向供电和地线电流路径，不能只凭“地都一样”随意连接。

## 万用表的三个入门用法

### 测直流电压

1. 黑表笔插 `COM`，红表笔插电压/电阻插孔。
2. 选择直流电压挡和合适量程。
3. 黑表笔接参考地，红表笔接被测点。
4. 先测电源输出，再测板端输入，比较两者是否一致。

### 测通断

通断挡适合在断电后检查导线、焊点或地线是否连通。蜂鸣只说明电阻较低，不代表这条线路在带载时一定可靠。

### 测电阻

测电阻前必须断电。电路中其他并联支路会影响读数，因此板上测量值不一定等于元件标称值。

## 第一次上电前的检查顺序

1. 对照原理图或接线说明确认正负极、接口方向和电压范围。
2. 断电测量电源正极与 GND，确认没有明显短路。
3. 设置合理的电压和限流，暂时断开电机等大负载。
4. 上电后先观察电源电流，再测逻辑电压。
5. 确认芯片没有异常发热、异味或声音。
6. 最后逐个接入传感器、驱动器和执行器。

> [!IMPORTANT]
> 如果电源立即进入限流、板上电压明显下降或器件快速升温，应立即断电。不要通过提高限流来“看看能不能恢复”。

## 常见现象怎样判断

| 现象 | 优先检查 |
| --- | --- |
| 下载正常，电机一动主控就复位 | 电源容量、压降、地线和电机干扰 |
| 传感器数值乱跳 | 共地、接触、电平范围和采样方式 |
| 电机完全不动 | 功率电源、使能、方向和 PWM 信号 |
| 板上电压正常但模块不工作 | 接口方向、信号时序和模块初始化 |
| 芯片或导线发热 | 反接、短路、过压和负载过大 |

这些只是排查入口，不是直接结论。每次仍应通过测量缩小范围。

## 怎样记录一次测量

| 项目 | 示例写法 |
| --- | --- |
| 测量目的 | 确认主控 3.3 V 电源是否稳定 |
| 被测两点 | 3V3 测试点与 GND |
| 仪表设置 | 直流电压挡，红表笔在电压插孔 |
| 预期范围 | 依据原理图、手册或老师给出的范围填写 |
| 实际结果 | 记录稳定值、波动范围和上电条件 |
| 处理结论 | 在范围内继续；异常则断电并检查供电路径 |

示例中的“预期范围”不能凭经验硬填。不同板卡、芯片和测量位置可能不同，必须回到当前原理图或数据手册。

## 本篇总结

- 电压是两个点之间的差，任何电平都需要参考点；电流流经回路，功率则反映能量转换与发热情况。
- 电机电源、逻辑电源、控制信号和 GND 职责不同。模块使用某个供电电压，不代表其所有信号都能直接接入主控。
- 万用表测电压时并联，测电流时串联，测电阻和通断前必须断电；不熟悉大电流测量时应先请老师或有经验的同学确认。
- 第一次上电应从断电检查、限压限流和逻辑电源开始，再逐步接入负载。遇到限流、压降、异味或快速升温时应立即断电。
