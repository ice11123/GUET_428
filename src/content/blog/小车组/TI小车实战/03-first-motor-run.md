第一次电机实验的目标不是“让车跑起来”，而是建立一个可控、可停止、能解释结果的最小测试。

## 本篇目标

本篇只完成一个最小闭环实验：架空车轮后，让单个电机在低指令下短时转动，随后可靠停机，并观察对应编码器计数是否变化。暂时不启动循迹、定距或整车任务。

| 阶段 | 可观察结果 | 不能据此推出 |
| --- | --- | --- |
| 逻辑上电 | 主控可下载、3.3 V/5 V 在确认范围内 | 电机功率链已经正常 |
| 单轮输出 | 目标轮按命令短时转动并能停下 | 速度闭环已经稳定 |
| 手转编码器 | 对应 QEI 计数连续变化 | 每圈计数和距离系数已标定 |

每一步只验证一个结论。任一阶段出现异常，就停在该阶段排查，不用提高 PWM 掩盖问题。

> [!WARNING]
> 上电前必须架空车轮，旁边保留可立即操作的断电开关。不要用手阻挡正在转动的车轮，也不要在电机堵转时继续增加 PWM。

> [!IMPORTANT]
> 下文的引脚、函数和量程来自当前 `TI_CAR_test1_6.7` 工作副本；供电电压与接口连接来自现有原理图说明。它们不是对任意 TB6612 小车都适用的通用参数，上板结果仍需现场测量。

## 上电前先理解电源

当前扩展板原理图中：

| 电源 | 用途 |
| --- | --- |
| 12 V | TB6612 的电机电源 `VM` |
| 5 V | TB6612 逻辑 `VCC`、编码器及部分模块供电 |
| 3.3 V | MSPM0G3519 GPIO 电源域 |
| GND | 主控、驱动器、编码器必须共地 |

必须特别注意两件事：

1. 调试器、外部 5 V 和板载 12 V 转 5 V 不能在未确认路径时随意并联，否则存在反灌风险。
2. 编码器由 5 V 供电，不代表其 A/B 相一定输出 3.3 V。首次接入前应查模块资料或用示波器、万用表确认高电平不会超过 MCU 允许范围。

原理图还显示 PA27 同时涉及蜂鸣器和 0～5 V 调参电位器。虽然当前固件没有把它用于电机控制，但进行整板测试时仍不能忽略这个潜在过压点。

## TB6612 的五类信号

### 电机电源和逻辑电源

- `VM` 为电机功率侧电源；
- `VCC` 为逻辑侧电源；
- 两者与主控共地。

不要把 `VM` 和 `VCC` 视为同一个电源脚。

### 方向信号

| 通道 | 正转组合 | 反转组合 |
| --- | --- | --- |
| 左轮 A | AIN1=1，AIN2=0 | AIN1=0，AIN2=1 |
| 右轮 B | BIN1=1，BIN2=0 | BIN1=0，BIN2=1 |

当前引脚为 AIN1=PB5、AIN2=PB10、BIN1=PB7、BIN2=PB6。

### PWM

- PWMA：PB14，对应 TIMA0 C0；
- PWMB：PA7，对应 TIMA0 C1。

生成配置显示 TIMA0 计数时钟为 1.8 MHz、周期为 1000，PWM 频率约为 1.8 kHz。`Motor_SetDuty()` 的软件输入范围是 `-1000` 到 `1000`，绝对值决定比较值，符号决定方向。

因此：

```text
Motor_SetDuty(..., 100)   → 约十分之一量程
Motor_SetDuty(..., 500)   → 约一半量程
Motor_SetDuty(..., -100)  → 低量程反向
```

它不是以 `-100%` 到 `100%` 为单位。旧快速手册中的百分比示例不适用于当前接口。

### STBY

`STBY=0` 时驱动器待机，`STBY=1` 时驱动器工作。当前引脚为 PB8。

`Motor_Start()` 采用以下安全顺序：

```c
DL_GPIO_clearPins(DIRC_CTRL_PORT, DIRC_CTRL_STBY_PIN);
Motor_SetDuty(&Motor_Font_Left, 0.0f);
Motor_SetDuty(&Motor_Font_Right, 0.0f);
DL_GPIO_setPins(DIRC_CTRL_PORT, DIRC_CTRL_STBY_PIN);
```

也就是先保持待机，再清零两路 PWM，最后才允许驱动器工作。这能降低初始化阶段突然转动的风险。

## 第一次实验的推荐顺序

### 第 1 步：断电检查

在所有电源断开的情况下：

- 检查 12 V、5 V、3.3 V 与 GND 是否短路；
- 对照接口方向，确认电机与编码器六针接口没有反插；
- 确认左右轮悬空，不会带动车体移动；
- 找到能够立即断开 12 V 电机电源的位置。

### 第 2 步：只验证逻辑电源

先不接电机功率输出，给主控和逻辑侧上电：

- 测量 3.3 V 和 5 V 是否稳定；
- 确认主控能够正常下载和运行；
- 检查 PB8 上电和初始化过程是否符合预期；
- 观察是否出现芯片异常发热。

### 第 3 步：单轮、低指令、短时间

不要直接启动完整循迹任务。可以在独立调试分支中，在 `SYSCFG_DL_init()` 后进行一次短时测试：

```c
Motor_Start();
set_motor_enable();

Motor_SetDuty(&Motor_Font_Left, 120.0f);
Delay(300);

set_motor_disable();
```

这里的 `120` 只是低量程起点，不保证所有电机都能克服静摩擦。如果电机不转，应小步增加并同时观察电流、声音和温升，而不是一次拉到最大值。

> [!TIP]
> 这段代码用于一次性冒烟测试，不能和完整 `Task_Init()` 控制流程长期并存。测试完成后应恢复正常入口，避免调试代码绕过状态机和安全停机逻辑。

### 第 4 步：确认方向

先测左轮，再测右轮：

1. 正指令时，两侧车轮对应的车辆运动方向都应是前进；
2. 负指令时应反转；
3. 停止后 PWM 应归零，PB8 应由 `set_motor_disable()` 拉低；
4. 如果只有右轮方向看起来相反，不要马上交换全部接线，先理解代码中的镜像极性：

```c
#define MOTOR_LEFT_OUTPUT_POLARITY 1
#define MOTOR_RIGHT_OUTPUT_POLARITY -1
```

软件已经为左右镜像安装做了一次方向变换。修改接线和修改极性只能选择一种清晰方案，不能两边同时试错。

### 第 5 步：手动验证编码器

电机断电或 `STBY` 拉低后，手动缓慢转动车轮，读取 TIMG8/TIMG9 的 QEI 计数变化。车辆前进方向应该产生正反馈。

当前代码按实际采样间隔计算转速：

```c
float rpm = ((float)encoder_value * 60000.0f) /
            (Motor_GetResolution(Motor) * (float)time);
```

检查要点：

- 静止时计数不应持续跳变；
- 向前转动时 RPM 符号应与目标速度一致；
- 左右轮转动相近时，计数数量级应接近；
- 16 位计数器回绕时，差值仍应连续；
- 换电机或减速比后，必须重新核对每圈计数与距离标定。

## 为什么左右轮不能直接使用同一个标定值

当前工程保存了左右轮独立的距离系数：

```c
#define MOTOR1_DISTANCE_CM_PER_COUNT 0.014773931f
#define MOTOR2_DISTANCE_CM_PER_COUNT 0.014690882f
```

它们来自当前车辆的重复距离测试。轮径、减速箱间隙、胎面和地面都会产生差异。新车可以沿用标定方法，但不应直接把这两个数字当作通用参数。

推荐标定流程：

1. 在固定地面上清零累计编码器；
2. 低速直行一段已知距离；
3. 分别记录左右轮累计计数；
4. 用多组距离拟合每计数对应的厘米数；
5. 用未参与拟合的距离验证误差。

## 常见故障排查

| 现象 | 优先检查 |
| --- | --- |
| 两个电机都不转 | 12 V、STBY、共地、PWM 是否真正输出 |
| 只有一个电机不转 | 对应 PWM 引脚、AIN/BIN、接插件和电机本体 |
| 一上电就高速转 | 初始化前 PWM 状态、STBY 时序、调试代码是否残留 |
| 正负指令方向相同 | AIN/BIN 组合或方向 GPIO 是否正确更新 |
| 主控一启动电机就复位 | 电源压降、地线、去耦、电机干扰和堵转电流 |
| 速度一直为零 | QEI 引脚、编码器供电、A/B 相信号和定时器是否启动 |
| PID 越调越快 | 编码器反馈符号与目标速度符号是否相反 |
| 速度跳变很大 | 采样间隔、接触不良、信号电平、编码器毛刺 |

## 安全停机应只有一个出口

当前底层提供：

```c
void set_motor_disable(void)
{
    Load_Motor_PWM(0.0f, 0.0f);
    DL_GPIO_clearPins(DIRC_CTRL_PORT, DIRC_CTRL_STBY_PIN);
    Flag.Is_EnMOTOR = 0;
}
```

这比只把目标速度设为零更可靠，因为它同时清零 PWM、让 TB6612 待机并更新软件状态。后续加入超时、急停或故障处理时，应尽量汇总到统一停机路径，而不是在不同任务里各写一套停止代码。

## 本篇总结

- TB6612 的 VM、VCC、GND、PWM、方向和 STBY 各有独立职责；正式接线前必须核对电源、电平和共地关系。
- 当前工程的电机指令范围是 `-1000..1000`，不能按旧文档把它解释成百分比。第一次运行应架空单轮，以低指令短时测试，并保证随时能够停止。
- 正负指令与机械方向、左右编码器的正反馈方向都需要实测和记录，不能只凭函数名或接线颜色判断。
- 电机启动时若出现主控复位、异常限流或过热，应立即断电并优先排查供电和接线；尚未确认的 5 V 信号电平必须继续标记为待测。
